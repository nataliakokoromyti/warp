Declare `__launch_bounds__` on HIP for kernels that do not set the `launch_bounds` option. Without it the compiler assumes a 1024-thread workgroup and caps the kernel at 128 VGPRs, so a kernel that needs more spills to scratch: mujoco_warp's SDF narrowphase spilled 465 VGPRs and its scene ran 1.43x slower on an MI350X. Kernels that already fit are unaffected, though a kernel sitting just under the cap can now be given more registers than its occupancy wants — set `launch_bounds` explicitly if a ROCm kernel regresses. CUDA code generation is semantically unchanged.
